# Portfolio / CV Bullets

- Built ALEPHZERO, a local AI engineering platform using Python, FastAPI, Ollama and Mistral for locally hosted LLM inference.

- Designed an agent-routing architecture capable of directing requests to calculators, system tools, time services, external APIs, RAG and general LLM inference.

- Implemented Retrieval-Augmented Generation using a local knowledge base to ground model responses in project-specific information.

- Integrated external REST APIs into the AI workflow, enabling the assistant to retrieve and process live API responses.

- Developed a centralized model gateway to abstract model configuration and inference from the rest of the application.

- Implemented telemetry and latency tracking as foundations for AI observability and MLOps.

- Applied modular software architecture, API-first design and controlled tool execution to an AI assistant.

- Packaged the project with technical documentation covering architecture, requirements, workflows, RAG, MLOps and product development lifecycle.
